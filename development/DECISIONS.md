## 2026-11-28 D007：历史回看与随机练习统一控制栏
用户要求上一题与当前题使用相同按钮位置，不再重新排列。两种模式共用持久练习框架和同一个 toolbar DOM 节点，固定顺序为朗读、停止、上一题、收藏、下一题。下一题标签统一；在历史中按顺序向前回看直至返回当前练习，当前练习继续随机抽题；历史列表保留直接返回入口。复习比例在两种模式中均保持可见及已保存值。历史题仍保留原选项顺序、选择、答案、笔记，不重新计分；取消自动跳题、防止朗读或收藏误作用于当前题。题库、学习记录、Auto Run 不修改。测试覆盖节点身份、顺序、回看导航和显示题回调；实际浏览器与部署状态以 PR/CI/Pages 验证为准。

## 2026-11-28 D008：仅显示分组计数与全题库轮次
用户明确确认：25/50/75/100 是显示学习进度的计数目标（默认50），不是分组题库、抽题限制或新练习模式。继续使用现有完整题库、原随机调度、复习比例及冷却，不修改 scheduler。每次实际提交答案（对错均计）或首次主动显示不懂答案，组计数加一；跳题、回看、收藏、重复标记已答题不增加计数。重复作答可计入组，但每轮全库完成度按不同有效题 ID 去重。组达到目标自动下一组并归零，全库所有有效 ID 完成后自动下一轮并归零，两者独立。调整组大小立即生效，保留当前已完成数量并按新目标自动结算，不丢弃进度。旧记录依据 lastSeen 有效ID迁移全库进度（不把累计次数误当完成题数），新组计数从0开始；累计次数、正确率、收藏、历史、笔记及原调度记录完全保留。按题库保存 studyProgress，随现有本地存储和备份恢复；不改变题库或 Auto Run。此方案是观察现有随机练习的实际覆盖，不保证固定次数内完成整轮。测试及部署以对应PR和Actions实际结果为准。

## 2026-11-29 D009：原始套题练习（用户明确新增功能）

## 2026-11-29 D010：原始套题内题目和选项均随机
用户明确确认：选择任意 Test 时，只能使用该 Test 的原有题目，但每轮题目顺序必须随机，答案选项也必须随机。每套每轮通过 Fisher–Yates 生成并保存题目 ID 排列；只从当前套未完成题中出题，跳过的题在本轮后续返回，已完成的题不重复。完成后点击再练一次生成新排列，避免连续两轮完全相同的顺序；保留独立成绩、完成次数、原题号、历史答题选项顺序和全部个人学习记录。旧顺序模式备份首次使用时保留已答结果，仅迁移随机排列。两种练习模式共用无副作用的选项洗牌函数，每次新出题均重新随机选项，正确答案文字与题库不变。全库调度、966条正式题目、套题归属及 Auto Run 不修改。测试覆盖全部套题、跳题、刷新恢复、旧备份迁移、重新练习、选项完整性和正确答案对应。实际部署以 CI/Pages 为准。
