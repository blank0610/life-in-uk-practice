## 2026-11-14 D001：完全独立
本项目仅使用 \`blank0610/life-in-uk-practice\`，不修改 \`stock-news-ai-2\`。只参考开发记录理念，分离开发笔记与正式网站。

## D002：静态网站
GitHub Pages 托管 \`site/\`。使用原生 HTML/CSS/JavaScript，无服务器或额外数据库。

## D003：等待正式题库
用户稍后会提供 ZIP；现在只建立网站与显著标记的示范题，绝不擅自导入之前的 QA.docx。

## D004：错题机制
随机题和随机排列答案。答错显示正确答案和解释，进入复习队列。可主动标记不懂。错题优先随机出现；复习正确两次后移出。学习记录仅留在本机浏览器，支持备份。

## D005：开发流程
\`develop\` 负责持续开发，\`main\` 负责 Pages 发布；开发说明放在 \`development/\`，只部署 \`site/\`。

## 2026-11-28 D006：每次 Auto Run 全库覆盖
用户要求每小时扫描全部正式题，不再限制每次12道。题数动态取自主账与 manifest，12仅为传输分包；独立全库扫描报告不冒充逐题人工审核或原图核验，不重置旧进度。现有 Auto Run 已实际更新，频率及项目隔离不变。详见 QUESTION_AUDIT_METHOD.md。

## 2026-11-28 D007：历史回看与随机练习统一控制栏
用户要求上一题与当前题使用相同按钮位置，不再重新排列。两种模式共用持久练习框架和同一个 toolbar DOM 节点，固定顺序为朗读、停止、上一题、收藏、下一题。下一题标签统一；在历史中按顺序向前回看直至返回当前练习，当前练习继续随机抽题；历史列表保留直接返回入口。复习比例在两种模式中均保持可见及已保存值。历史题仍保留原选项顺序、选择、答案、笔记，不重新计分；取消自动跳题、防止朗读或收藏误作用于当前题。题库、学习记录、Auto Run 不修改。测试覆盖节点身份、顺序、回看导航和显示题回调；实际浏览器与部署状态以 PR/CI/Pages 验证为准。
