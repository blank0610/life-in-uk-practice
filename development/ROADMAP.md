# Life in the UK · 开发地图

## 项目范围
仓库为 \`blank0610/life-in-uk-practice\`。与 \`stock-news-ai-2\` 完全隔离。本项目只读借鉴其开发笔记形式，不共享代码、数据、自动化、部署。

## 区域
- \`site/\`：网站本身，仅此目录公开发布到 GitHub Pages
- \`development/\`：长期开发记录
- \`develop\`：功能开发分支；\`main\`：正式网站；\`Issues\`：日后需求与 Bug；\`Pull Request\`：合并审核
- \`examples/\`：数据契约示例

## 阶段
- **W00 网站基础（已编写）**：手机友好、演示题、随机题目与选项、自动判断、错题队列、答错显示答案与解释、标记不懂、复习两次正确移除、本地进度、备份恢复、Pages 工作流。
- **W01 用户 ZIP 导入（等待提供）**：以后才解包、解析、去重和检查题目；不导入之前的 QA 文档。
- **W02 数据质量（待做）**：核实题干、标准答案、错误选项、是否过时、是否需要多选、版权合规。
- **W03 正式题库上线（待做）**：审核后更新 \`site/data/questions.js\` 并通过测试。
- **W04 后续优化（待讨论）**：分类练习、间隔复习、学习统计、跨设备备份体验。

## 后续每次开发
1. 在本仓库创建 Issue，记录目标和验收标准。
2. 在 \`develop\` 上修改、记录决定，不要直接把未审核修改推至 \`main\`。
3. 跑自动测试（可扩展）。
4. Pull Request \`develop → main\`，核对后合并。
5. 确认 GitHub Pages 工作流与真实网页成功；更新开发记录。

注意：GitHub commit 成功不等于 Pages 发布成功，必须单独验收。
