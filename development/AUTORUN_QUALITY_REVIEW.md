# Life in the UK · 独立题库自动审查（Auto Run）

## 使用者授权
一个专属 ChatGPT Auto Run（不是 GitHub Actions 的额外定时工作流），每小时检查 **blank0610/life-in-uk-practice**，维护题库的英文拼写与内容一致性。

## 只允许的项目
- 仓库：`blank0610/life-in-uk-practice`
- 默认读取：`main` 目前网站代码、当前全部 ZIP 截图题的数据和校对记录、最近 PR / Issues / Actions。
- **严禁访问、修改、重启或复用 Stock AI 2 的任意 Auto Run、GitHub 仓库、Issue、分支、配置或工作流。**

## 每次审查（2026-11-28 用户最新要求）
1. 每次从第一题开始扫描全部正式题库，动态读取主账 bankCount 与 manifest 所有分包。12 道仅为文件大小，不是任务上限。
2. 以最新 main SHA 实际读取、检查每道题的题干、全部选项、答案及解释；记录全库覆盖和疑点至 development/FULL_BANK_AUDIT_LATEST.json。规则扫描不等于逐字人工或原图核验。
3. 保留原有逐题证据主账及历史。能读取图片时实际比对；不能读取时明确记录限制。只修复经原图确认的 OCR、拼写、缺漏及符号差异；不查外部事实，不擅自更新历史、法律和答案，不润色原题。
4. 已确认的改动通过开发分支、PR、测试和真实部署验证；不确定项记录待核验。
5. 仅有新重要发现、已修复问题、覆盖不完整、测试失败或需要用户行动时通知。

## 启用状态
