## 英语语音朗读

- 在每道题上按 **🔊 朗读题目与全部选项**：按当前随机显示顺序朗读，不会在作答前读出正确答案。
- 作答后按 **🔊 朗读正确答案与解释**：读英文正确答案及解释；点击后暂停答对题目的自动换题，听完按 **下一道随机题** 继续。
- **■ 停止朗读** 可随时停止，换题、离开练习页或作答时也会自动停止上一段朗读。
- 采用浏览器系统原生 Web Speech API（SpeechSynthesis），优先选择英式英语 \`en-GB\`，没有则回退到其他英语声音。无需付费 API、无麦克风权限。是否有英式语音取决于设备和浏览器，有些语音引擎由操作系统或浏览器管理。
- 这是英语**朗读**而非英文发音评分；用户仍需自己选择答案，错题和复习机制不变。


## 自动下一题开关

- 在 **随机练习** 标题旁的 **答对自动下一题** 勾选框，随时选择开启或关闭。
- **开启（默认）**：答对后保留短暂的正确答案说明，再自动随机进入下一题；如正在朗读正确答案，则暂停自动切换。
- **关闭**：答对后保持当前题目和解释，直到手动点击 **下一道随机题 →**，答错时始终手动下一题。
- 选择保存在本机浏览器的学习记录中，重新打开网页仍然生效；导出学习记录也会保存此设置，旧版本备份默认开启。
- 不影响已有的随机抽题、错题再练、70% 冷却比例或 487 道题目。

### 下一道随机题按钮位置

- 「下一道随机题 →」现在与「🔊 朗读题目与全部选项」「■ 停止朗读」显示在练习卡同一控制栏，方便随时切换。
- 按钮在答题前后均可用：尚未作答直接跳题不计为错误；答对或答错后继续下一题。
- 屏幕较窄时控制栏自动换行，避免文字被遮住。
- 批改解释区域不再重复显示此按钮；自动下一题开关、语音朗读、错题模式保持原功能。

## 最近五题回看和笔记（本机保存）

- 练习页「朗读 / 停止 / 上一题 / 下一道随机题」控制栏新增 **← 上一题**，答完题后可返回之前答过的题；也可以点击题卡下方「最近五次作答」的历史标签。
- 保留**最近五次已经完成的答题记录**（相同题目重复作答会分别保存），包括当时实际显示的选项顺序、自己选择的答案、正确答案、解释以及个人笔记。未作答就随机跳过的题不会占用这五条记录。
- 在历史页点击 **← 上一题 / 下一条历史 / 返回当前练习** 自由浏览，最多回看五条历史记录。历史选项只能看，不能重新提交或重复计分；返回当前练习后，未提交的多选选择也不会丢失。
- 答对或答错后均可填写学习笔记，**输入时自动保存**。历史页可修改当时的笔记；如果正在编辑答案说明，自动换题计时会暂停。
- 历史记录和笔记位于当前浏览器的 localStorage，并随「导出学习记录 / 恢复学习记录」JSON 备份。旧版本学习记录自动兼容，但旧答题历史无法凭累计次数倒推出具体答案。
- 不修改 487 道正式题、错题学习算法、已保存的正确率、自动下一题开关或语音朗读；网站不会将私人答题笔记上传到 GitHub。
