**这是独立于 Stock AI 2 的英国生活考试练习网站。**

## 网站和开发区域

- \`site/\`：GitHub Pages 公共网站（随机抽题、随机打乱答案、自动批改、错题重练、备注、进度本机保存）

## 英语语音朗读

- 在每道题上按 **🔊 朗读题目与全部选项**：按当前随机显示顺序朗读，不会在作答前读出正确答案。
- 作答后按 **🔊 朗读正确答案与解释**：读英文正确答案及解释；点击后暂停答对题目的自动换题，听完按 **下一道随机题** 继续。
- **■ 停止朗读** 可随时停止，换题、离开练习页或作答时也会自动停止上一段朗读。
- 采用浏览器系统原生 Web Speech API（SpeechSynthesis），优先选择英式英语 \`en-GB\`，没有则回退到其他英语声音。无需付费 API、无麦克风权限。是否有英式语音取决于设备和浏览器，有些语音引擎由操作系统或浏览器管理。
- 这是英语**朗读**而非英文发音评分；用户仍需自己选择答案，错题和复习机制不变。


## 自动下一题开关

- 在 **随机练习** 标题旁的 **答对自动下一题** 勾选框，随时选择开启或关闭。
- **开启（默认）**：答对后保留短暂的正确答案说明，再自动随机进入下一题；如正在朗读正确答案，则暂停自动切换。
- **关闭**：答对后保持当前题目和解释，直到手动点击 **下一道随机题 →**，答错时始终手动下一题。
- 选择保存在本机浏览器的学习记录中，重新打开网页仍然生效；导出学习记录也会保存此设置，旧版本备份默认开启。
- 不影响已有的随机抽题、错题再练、70% 冷却比例或 487 道题目。

### 下一道随机题按钮位置

- 「下一道随机题 →」现在与「🔊 朗读题目与全部选项」「■ 停止朗读」显示在练习卡同一控制栏，方便随时切换。
- 按钮在答题前后均可用：尚未作答直接跳题不计为错误；答对或答错后继续下一题。
- 屏幕较窄时控制栏自动换行，避免文字被遮住。
- 批改解释区域不再重复显示此按钮；自动下一题开关、语音朗读、错题模式保持原功能。

## 最近五题回看和笔记（本机保存）

- 练习页「朗读 / 停止 / 上一题 / 下一道随机题」控制栏新增 **← 上一题**，答完题后可返回之前答过的题；也可以点击题卡下方「最近五次作答」的历史标签。
- 保留**最近五次已经完成的答题记录**（相同题目重复作答会分别保存），包括当时实际显示的选项顺序、自己选择的答案、正确答案、解释以及个人笔记。未作答就随机跳过的题不会占用这五条记录。
- 在历史页点击 **← 上一题 / 下一条历史 / 返回当前练习** 自由浏览，最多回看五条历史记录。历史选项只能看，不能重新提交或重复计分；返回当前练习后，未提交的多选选择也不会丢失。
- 答对或答错后均可填写学习笔记，**输入时自动保存**。历史页可修改当时的笔记；如果正在编辑答案说明，自动换题计时会暂停。
- 历史记录和笔记位于当前浏览器的 localStorage，并随「导出学习记录 / 恢复学习记录」JSON 备份。旧版本学习记录自动兼容，但旧答题历史无法凭累计次数倒推出具体答案。
- 不修改 487 道正式题、错题学习算法、已保存的正确率、自动下一题开关或语音朗读；网站不会将私人答题笔记上传到 GitHub。

## 自己收藏稍后复习的题目

- 练习题朗读工具栏新增 **☆ 收藏稍后复习**。无论还没答题、答对或答错，都可以点击收藏。
- 收藏后按钮显示 **★ 已收藏 · 取消**。收藏题和答错、不懂的题共享随机复习调度：在普通随机练习中会提前再次出现，也会显示在 **错题与收藏** 专项练习页面。
- **收藏并不算答错**，不会改变累计答题数、正确率或答错次数。收藏题完成两次正确练习后仍保留收藏，直到主动取消。
- 在「错题与收藏」列表、最近五题回看界面也可取消收藏。如果某题本来答错、还需复习，取消收藏**不会**删掉它原本的错题状态。
- 收藏会存入现有浏览器学习记录，并随 JSON 学习备份一同导出 / 恢复；不上传用户笔记或个人记录到 GitHub。

## 百分比随机混合普通题与错题／收藏题

- 在「随机练习」题目下方显示 **下题随机比例：普通题 70% · 错题／收藏题 30%**，不再显示 `0/26` 这类固定题数的等待进度。
- **每一次抽取**都按当前百分比概率选择普通题或复习题。复习池包括答错、标记不懂及手动收藏的题目；从池内再随机抽具体题目。没有可用复习题时继续抽普通题；普通题暂时用完时也不会卡住。
- 在「题库与备份 → 错题与收藏题的随机出现比例」调整**普通题比例**，范围 0–100%，每次调整 5%；复习题比例自动计算为 100% 减去普通题比例。默认 70% 普通题、30% 复习题。这是长期抽取概率，并不承诺每 10 题恰好 7 道普通和 3 道复习。
- **专项复习**始终只抽答错／不懂／收藏题，不受该百分比分配限制。
- 普通题答对后原有的 **70%「其他不同题」冷却规则**仍保留；它用于控制已答对的普通题何时可再次进入普通池，与本次的 **70% 普通题抽取概率**是两项独立的设置。
- 百分比与原有自动下一题开关一起保存在本机浏览器、学习记录备份中；升级旧版后默认 70/30，旧的 `redoRange` 和批次计数仅作为历史数据保留、不再用于调度。你的成绩、错题、收藏、最近五题和笔记不会被清除。

## 查看公开的题库审核记录

- 网站侧边栏的 **☑ 题库审核记录** 直接读取独立 GitHub 公开仓库中的 `development/QUESTION_AUDIT_PROGRESS.json`，显示已合并的顺序审核进度、每道题的检查日期、发现的问题、原图是否真正核对。
- **待合并的 GitHub 审核 PR 不计入主分支进度**，但会单独列出，并给出直接打开 PR 的链接。已合并的拼写/答案修复、审核提交（Commit）也可在同一页查看。
- 针对用户要求单独核对的题目，记录在 `development/ON_DEMAND_CHECKS.json`；如 #316 通过原 ZIP 原图及英国国防部资料确认答案 2009 正确，题库无需改动。此类抽查**不影响**按题号顺序进行的 487 题审核计数。
- 页面每次打开或按「刷新 GitHub 记录」时读取最新公开 GitHub 数据，不依赖浏览器的学习进度，也不展示任何用户的答题笔记。需要联网访问 GitHub；若受限，页面提供 GitHub 原始记录链接。
- **关于 Auto Run：** 网站显示的是已写入 GitHub 的审核证据，不是 ChatGPT 内部调度器的实时执行列表。任务每小时运行不意味着当小时一定有新的入库结果；原始图片未能读取时只标记文字初检，绝不冒充原图核验。
